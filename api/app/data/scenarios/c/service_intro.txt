[가상 데이터] C사 서비스 소개서
C사(가상)는 의료 영상 소프트웨어를 만드는 회사입니다.
흉부 영상 판독 보조 기능은 병원에 공급하는 B2B 제품으로, 흉부 엑스레이에서 병변이 의심되는 영역을 화면에 표시해 영상의학과 전문의의 판독을 돕습니다.
흉부 영상 판독 보조가 병변을 놓치거나 잘못 표시하면 환자의 생명과 신체에 중대한 영향을 줄 수 있어 의료기기로 관리합니다.
흉부 영상 판독 보조의 표시 결과는 그대로 확정되지 않으며, 최종 판단은 전문의가 영상을 직접 확인한 뒤 판독문에 서명해야 내려집니다.
현재 종합병원 12곳에서 사용 중입니다.
