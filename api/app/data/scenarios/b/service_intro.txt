[가상 데이터] B사 서비스 소개서
B사(가상)는 기업 고객사 인사팀에 채용 솔루션 '채용 도우미'를 공급합니다.
지원서 자동 평가 기능은 기업 고객의 채용 공고에 들어온 지원자의 지원서를 점수화하며, 기준 점수 미만 지원자는 자동으로 탈락 처리됩니다.
지원서 자동 평가의 탈락 결과는 사람의 검토 없이 지원자에게 바로 통보됩니다.
면접 답변 분석 기능은 화상 면접에서 지원자의 답변을 분석해 합격 여부 추천을 기업 고객에게 제시합니다.
면접 답변 분석의 추천 결과는 인사팀이 내용을 열어 보지 않고 일괄 승인하는 형식적 절차만 거칩니다.
두 기능 모두 현재 운영 중이며 연간 약 5만 건의 지원서를 처리합니다.
